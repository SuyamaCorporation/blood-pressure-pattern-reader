## 血圧パターン読み解きツール

朝晩の血圧測定値を記録してグラフ表示・パターン分析を行う、医師相談材料としての血圧管理ツール。

### 機能
- 測定値入力: 日付・時間帯（朝/昼/晩）・収縮期・拡張期・脈拍
- 折れ線グラフ（Canvas 2D）: 収縮期/拡張期の推移
- WHO分類判定ライン（正常/高め/高血圧I度/II度）を背景色帯で表示
- 統計サマリー: 平均・最大・最小・変動係数（CV）
- パターン警告説明カード: 白衣高血圧・仮面高血圧の解説
- localStorage: 測定記録保存（最大90日分）
- CSVエクスポート（BOM付き UTF-8）

### 技術
- 静的SPA（index.html単体）
- Tailwind CSS CDN
- Canvas 2D API（血圧推移グラフ・WHO背景帯）
- localStorage（JSON 測定記録保存）
